description: Monster Meta — first-run setup (validate Meta token, discover accounts/pages/pixels, write config)
---

Invoke the **monster-meta** skill and run its `setup` workflow (`tasks/setup.md`): call `whoami`
to validate the Meta access token, discover the user's ad accounts, pages, and pixels, and write
their `account-config.md`. If the token is missing or invalid, point the user to
`docs/meta-token-setup.md`.
