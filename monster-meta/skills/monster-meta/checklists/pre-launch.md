# Pre-Launch Checklist

**Purpose:** Quality gate before activating any Meta ad campaign. Every item must pass before setting status to ACTIVE.

## Tracking & Attribution
- [ ] Facebook Pixel installed on destination page
- [ ] Conversions API (CAPI) configured and sending events
- [ ] Correct conversion event selected for optimization (e.g., Lead, Purchase)
- [ ] UTM parameters appended to destination URL
- [ ] Test event fired and visible in Events Manager

## Campaign Structure
- [ ] Objective matches business goal (ODAX format)
- [ ] Naming convention followed for campaign, ad set, and ad
- [ ] No special ad category violations (housing, credit, employment)
- [ ] Campaign status is PAUSED (not prematurely activated)

## Targeting
- [ ] Geographic targeting matches intended market
- [ ] Age range appropriate for audience (not over-restricted)
- [ ] Interest/behavior IDs validated via MCP tools
- [ ] Estimated audience size is viable (not too narrow <100K or too broad >50M for budget)
- [ ] Advantage+ Audience configured correctly (enabled or disabled intentionally)
- [ ] No accidental audience exclusions

## Budget & Bidding
- [ ] Budget amount correct (double-check cents conversion)
- [ ] Bid strategy matches optimization goal
- [ ] Budget sufficient for learning phase (50 conversions/week per ad set at target CPA)
- [ ] Start/end dates correct (if using lifetime budget or scheduled delivery)
- [ ] Campaign budget optimization (CBO) vs ad set budget (ABO) choice is intentional

## Creative
- [ ] Image meets specs: 1080x1080 minimum, <30MB, supported format
- [ ] Video meets specs: aspect ratio correct, <4GB, captions included
- [ ] Primary text within recommended length (125 chars visible)
- [ ] Headline within recommended length (40 chars)
- [ ] No text overlay exceeding 20% of image area
- [ ] CTA button matches campaign objective
- [ ] Destination URL loads correctly and is mobile-optimized
- [ ] Instagram Actor ID set (if running on Instagram)

## Compliance
- [ ] Ad complies with Meta Advertising Standards
- [ ] No prohibited content (misleading claims, discriminatory targeting)
- [ ] Landing page matches ad promise (no bait-and-switch)
- [ ] Privacy policy accessible on landing page
